# Nested Structure with Pointer to Nested Structure

## Author
M.Likitha

## Description
This program demonstrates accessing a nested structure
through a pointer.

The Employee structure contains a Department structure.
A pointer is created specifically for the nested Department
structure and its members are accessed using the -> operator.

## Concepts Used
- Structure
- Nested structure
- Structure pointer
- Pointer to nested structure
- Arrow operator (->)

## How to Run

gcc nested_structure_pointer.c -o nested_structure_pointer

./nested_structure_pointer
